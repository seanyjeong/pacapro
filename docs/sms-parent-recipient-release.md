# 문자 수신자 분리 (4.0.55)

`/sms`와 `/tablet/sms`의 전체·개별 발송에서 학생, 아버님, 어머님, 학부모 대표번호를 각각 선택한다. 아버님은 `father_phone`, 어머님은 `mother_phone`, 대표번호는 기존 `parent_phone`만 사용한다. 대표번호만 저장된 학생의 부모 역할은 추측하지 않는다. 두 부모님께 각각 보내려면 두 대상을 별도로 선택·확인해 발송한다. 같은 대상 안에서 중복된 전화번호는 한 번만 발송하며, 수신자 수 집계도 같은 기준을 사용한다.

기존 대표번호 선택과 학생 선택, 직접 입력, 자동 문자·알림 동작은 유지한다. 개별 학생 검색과 학생 상세에서 이동한 문자 화면 모두 두 부모님 번호를 표시한다. 선택한 역할에 번호가 없으면 발송 확인으로 진행하지 않는다. 이 변경에는 DB migration·환경 변수·의존성 변경이 없다.

운영 적용은 `DEPLOYMENT.md`의 PACA 제한 핫픽스 절차를 따른다. 백엔드 실행 파일 `routes/sms.js`, `routes/sms/auxiliary.js`, `services/smsRecipientService.js`를 체크섬 백업·대조 후 교체하고 `paca-failover.service`만 재시작한다. 백엔드 수신자 수 조회와 실제 발송은 서로 같은 대상 선택 함수를 사용한다. 문자 업체로 시험 발송하지 않고 합성 번호를 사용한 API·브라우저 테스트 및 운영 읽기 전용 수신자 수 조회로 확인한다. 프론트는 롤백 태그를 만든 뒤 4.0.55를 푸시하고 Vercel READY·실제 버전 표시를 확인한다. 앱 롤백은 백업한 위 파일과 이전 프론트 태그를 복원하면 되며 DB 복원은 필요 없다.
