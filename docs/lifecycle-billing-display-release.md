# 휴원·퇴원 일할 청구 및 휴원 날짜 수정 (4.0.58 / API 4.0.23)

휴원 시작일만 수정해도 서버에서 청구를 다시 계산한다. 처리 전 미리보기와 저장 결과에서 원금·일할 금액·납부액·미납액·미사용 납부액을 표시한다.

계산은 시작일 전날까지 해당 월의 달력 일수로 나누고 천 원 미만을 절삭한다. 이전 일할 금액이 아닌 보존된 원금으로 계산하며, 월을 넘기는 수정도 해당 휴원의 감사 이력으로 정산한다. 퇴원은 현재 월 일할 금액을 유지하고 이후 월 미납 청구를 정산한다. 실제 납부와 매출 이력은 보존하며 외부 환불은 자동 실행하지 않는다.

원금·기존 크레딧·수동 정산과 충돌하면 날짜와 청구 모두 변경하지 않고 409를 반환한다. 미리보기 이후 청구가 바뀌어도 전체 저장을 중단한다. 이미 삭제된 청구를 복원하지 않는다.

검증: 관련 백엔드 149건, 화면 회귀 8건, 격리 MySQL 8.4 실제 HTTP/트랜잭션 30건 통과. 변경 코드 ESLint, TypeScript, Next.js production build 및 Node 18 문법 통과. MySQL 최초 실행의 2개 실패는 원금과 청구액이 다른 시험 fixture를 수정하여 해결했으며 운영 보호 로직은 유지했다.

배포: 운영 4.0.22의 324개 런타임 파일과 기준 069930c의 동일성을 확인했다. 변경 백엔드 17개만 백업 후 교체하며 PACA 서비스만 재시작한다. 프론트는 백엔드 확인 뒤 Git main/Vercel로 배포한다. 스키마 및 환경 변경은 없다.

기존 휴원 청구 보정은 scripts/repairPausedTuition.js의 읽기 전용 계획과 원본 해시를 확인한 뒤 명시 --apply로 수행한다. 정확한 교육원 이름·id·원장 id를 검증하고 한 트랜잭션으로 저장한다. 운영 실제 결과는 별도 2026-10-09 배포 기록에서 확인한다.
